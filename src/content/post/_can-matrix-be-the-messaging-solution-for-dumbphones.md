In 2026, most of the world communicates using platforms like WhatsApp, Telegram, iMessage, and Google RCS.

Being free, very well featured, and accessible to almost everyone, these platforms are used in every area of life; from workplace discussions and family group chats, to direct messaging and voice calls.

This works for almost everyone - except for minimalist and kosher phone users.

Most modern dumbphones don't support these platforms.

Some phones block them because the platforms can have distracting features and design, others because the phone is too dumb to be able to run the app.

People using these phones are usually forced to rely on SMS & MMS text messaging, which is too limited for many use cases, including most group chats.

### Matrix: An open alternative

Matrix is an open-source, decentralized messaging protocol.

You can think of it as the messaging equivalent to email.

With email, you can open Gmail, and message someone who uses Outlook, iCloud or Proton.

You can access your emails from any app that supports standard email protocols, like Thunderbird or K-9 Mail, even though it has no affiliation with the email service you use. 

Matrix works the same way.

No one owns Matrix.

You can use whichever Matrix server you want, and message someone using any other Matrix server.

You can use any Matrix app you want.

It's an open system that anyone can work with.

### A mature, fully featured platform

Matrix has all the features you'd expect from a modern messaging platform.

It allows group chats, voice notes, end-to-end encryption, media sharing, read receipts, and voice and video calling.

It's a tool trusted by tens of millions of users worldwide, major tech ecosystems like Mozilla and KDE, and entire European governments, including the French civil service and the German healthcare system, for secure, mission-critical communication.

### What does this have to do with messaging on dumbphones?

Because Matrix is an open protocol, any developer can build their own Matrix app.

That means that it's possible to build a Matrix client that's as minimalist as you want, choosing whichever features to include.

You can have one that blocks media attachments, or groups over a certain size, or any other features of Matrix you don't like.

You can have Matrix clients that are d-pad and small-screen friendly.

There are already phones like the Sunbeam that have this concept for email.

There's no reason not to have it for messaging.
